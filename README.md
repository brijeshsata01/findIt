
# FindIt – Lost and Found Items Management System

## Project Overview
FindIt is a web-based campus Lost and Found Items Management System.

## Project Type
Individual Final Semester MCA Project

## Technology Stack
- MongoDB
- Express.js
- React.js
- Node.js

## Main Users
1. Student
2. Admin

## Main Features
- Student Registration and Login
- Lost Item Reporting
- Found Item Reporting
- Item Photo Upload and Viewing
- Search and Filter Items
- Claim Request Management
- Admin Dashboard
- Item Verification
