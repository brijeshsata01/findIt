
# FINDIT – METHODOLOGY AND FEASIBILITY

## 1. Proposed Methodology

The FindIt project will follow an Agile-inspired
iterative software development approach.

The project will be divided into smaller
development modules. Each module will be
designed, implemented, tested and improved
before proceeding to the next major module.

## 2. Software Development Life Cycle (SDLC)

The following phases will be followed:

### 2.1 Requirement Analysis
Identify and analyze the requirements
of students and administrators.

### 2.2 Planning
Prepare project schedules, milestones
and development tasks.

### 2.3 System Design
Design the system architecture, database
structure, diagrams and user interfaces.

### 2.4 Development
Develop the frontend using React.js
and backend using Node.js and Express.js.

### 2.5 Database Integration
Use MongoDB to store student accounts,
item reports and claim information.

### 2.6 Testing
Test application functionality, APIs,
authentication and image upload features.

### 2.7 Deployment
Deploy the completed application
using suitable hosting services.

### 2.8 Maintenance
Fix bugs and improve application
functionality when required.

## 3. Iterative Development Approach

The project will be developed through
the following iterations:

1. Authentication Module.
2. Lost and Found Reporting Module.
3. Image Upload Module.
4. Search and Filter Module.
5. Claim Management Module.
6. Admin Dashboard Module.
7. Integration and Testing.

## 4. Feasibility Study

### 4.1 Technical Feasibility

The project will use the MERN Stack,
including MongoDB, Express.js, React.js
and Node.js.

Visual Studio Code, Git and GitHub will
be used as development tools.

The required technologies are suitable
for developing a web-based Lost and
Found Management System.

Therefore, the project is technically
feasible with the available resources
and planned configurations.

### 4.2 Cost and Resource Feasibility

The project will primarily use free and
open-source development technologies.

Existing computer hardware, internet
connectivity and development tools will
be utilized.

Free service tiers may be used for
database hosting, image storage and
application deployment, subject to
their usage limitations.

Therefore, the initial development cost
is expected to remain low.

### 4.3 Practical Applicability and
Project Relevance

FindIt is intended to provide a centralized
Lost and Found platform for university
campuses.

It will help students report lost and found
items, upload photographs, search item
records and submit claim requests.

Administrators will be able to manage
reports, verify claims and update item
statuses.

The proposed system aims to improve
the organization and accessibility of
campus Lost and Found information.
