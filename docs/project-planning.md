
# FindIt – Project Planning

## 1. Project Information

Project Title:
FindIt – Lost and Found Items Management System

Project Type:
Individual Project

Degree:
Master of Computer Applications (MCA)

Academic Year:
2026-27

Technology:
MERN Stack

## 2. Project Definition

FindIt is a web-based Lost and Found Items
Management System designed specifically for
university campuses.

The system provides a centralized platform
where students can report lost and found
items by uploading photographs and entering
relevant item details.

Students can search for items, view available
reports, and submit claim requests.

Administrators can manage student reports,
verify item information, review claim requests,
and update item statuses.

The main purpose of FindIt is to simplify the
process of finding lost belongings and improve
communication between students and campus
administration.


## 3. Problem Statement

In a university campus, students frequently
lose personal belongings such as mobile phones,
wallets, identity cards, books, laptops, and
other important items.

Currently, students may depend on friends,
faculty members, security staff, or informal
communication to report and search for lost
items.

This process can be time-consuming and may
make it difficult to identify the rightful owner
of a found item.

There is a need for a centralized digital
platform where students can report lost and
found items, upload photographs, search for
available items, and submit claim requests.

FindIt aims to address this problem by
providing a web-based system that organizes
lost and found item information and allows
administrators to manage reports and claims.


## 4. Objectives

1. To develop a centralized Lost and Found
   Management System for university campuses.

2. To allow students to report lost and found
   items online.

3. To provide photo upload functionality for
   both students and administrators.

4. To allow students to search and filter
   reported items.

5. To provide a claim request system for
   students who identify their lost belongings.

6. To allow administrators to verify and
   manage item reports.

7. To maintain item status and claim records.

8. To develop a secure, responsive, and
   user-friendly web application.


## 5. Scope of the Project

The FindIt system will be designed for
university campus use.

The system will include the following scope:

### Student Module
- Student registration and login.
- Reporting lost and found items.
- Uploading item photographs.
- Searching and filtering items.
- Viewing item details.
- Submitting claim requests.
- Tracking report and claim status.

### Admin Module
- Admin authentication.
- Managing student accounts.
- Viewing and managing item reports.
- Uploading and viewing item photographs.
- Verifying reported items.
- Approving or rejecting claim requests.
- Updating item status.

### System Scope
- Centralized item information management.
- Image storage and retrieval.
- Secure access to user accounts.
- Responsive web interface.
- Database management of reports and claims.

### Limitations
- Initially designed for a single university campus.
- Requires an internet connection.
- Claim approval depends on ownership verification.
- Automatic identification of item owners is not included.
